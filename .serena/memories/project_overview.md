# Project Overview: GearPit

**Purpose**: A unified maintenance log and configuration management platform for serious hobbies (Skiing, Mountaineering, Motorcycles, PC Building).

**Type**: Cloud-Native Monorepo tailored for ARM64 home-lab infrastructure.

**Key Characteristics**:
- **Target Infrastructure**: Raspberry Pi 5 Cluster (k3s).
- **Architecture**: Clean Architecture with strict layering.
- **Deployment**: GitOps via ArgoCD (App of Apps Pattern & PR Previews).
